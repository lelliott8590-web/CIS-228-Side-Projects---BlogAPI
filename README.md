A REST API for a blog, built with Django 6.1 and Django REST Framework. Users can sign up, log in and out, and reset their password through dj-rest-auth and django-allauth, using either session or token authentication. Each post has a title, body, author, and timestamps, and the API supports full create, read, update, and delete through viewsets and a router. Only a post's author can edit or delete it, and every endpoint requires a logged-in user. The project uses a custom user model (`accounts.Customuser`), and CORS is set up so a frontend on `localhost:3000` can connect.

Main endpoints are `/api/v1/` (posts), `/api/v1/users/` (read-only user list), `/api/v1/dj-rest-auth/` (login, logout, password reset), and `/api/v1/dj-rest-auth/registration/` (sign up). Interactive API docs generated by drf-spectacular are at `/api/schema/swagger-ui/` and `/api/schema/redoc/`. To run it locally, create and activate a virtual environment, then run `pip install -r requirements.txt`, `python manage.py migrate`, `python manage.py createsuperuser`, and `python manage.py runserver`. Run the tests with `python manage.py test`.
